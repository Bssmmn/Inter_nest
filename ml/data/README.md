# Data acquisition

The original study deposited data and replication code at [Harvard Dataverse](https://doi.org/10.7910/DVN/GUATS6). This analysis uses the documented, standardized [IRW conjoint table v5.0](https://itemresponsewarehouse.org/tables/shafranek_2021_roommate_choice/), listed as CC0 1.0. The original archive was inaccessible during this run. IRW reconstructs the task/profile positions, which serve only as audit and evaluation keys.

Save the [versioned public export](https://redivis.com/api/v1/tables/datapages.irw_conjoint:v5_0.shafranek_2021_roommate_choice/rows?format=csv) here as `shafranek_2021_roommate_choice.csv`. Keep the bytes unchanged. The notebook validates SHA-256 before loading and prints only aggregates. The export contains sensitive study fields excluded from the predictors and version control.
